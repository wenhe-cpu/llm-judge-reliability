# LLM-as-a-Judge 评测可靠性诊断

用受控实验量化"让大模型当裁判"时的系统性偏差。

**核心结论**：在 50 组配对、200 次判定中，仅调换两个回答的输入顺序，就有 **54%** 的判定发生翻转；模型选择"标为 A 且位于首位"一方的比例为 **70%**；**200 次判定中没有出现一次平局**。

> 一句话：这个裁判不是在比较内容，它在比较位置。

---

## 核心发现

| 指标 | 数值 | 含义 |
| --- | --- | --- |
| 换序后判定翻转率 | **54%**（27/50） | 内容完全不变，仅顺序改变 |
| 选择"标为 A 且位于首位"一方 | **70%**（140/200） | 存在强烈的标签/位置先验 |
| 平局率 | **0%**（0/200） | 从不弃权，即使质量相当也必选一个 |
| 长度膨胀 1.5× 后的胜率变化 | 36% → 32% | 加长**没有**带来优势 |

分任务翻转率：写作 47%、知识 55%、推理 60%。

### 一个被证伪的假设

实验前有一个合理猜想：**当长度线索被中和后，模型会转而依赖位置线索**（判据替换）。50 组数据不支持这个假设——等长与不等长条件的顺序一致率完全相同（46% vs 46%），说明两者本来就是同一种行为。

> 这个假设在 n=3 的预实验中曾看起来成立。**小样本会主动编故事，而且编得很像真的。**

---

## 实验设计

2×2 对照，两个因子：**长度**（等长 / 不等长）× **顺序**（正序 / 换序）。

| 条件 | 输入 | 用途 |
| --- | --- | --- |
| C1 | 等长，正序 | 基线 |
| C2 | 等长，换序 | 隔离位置效应 |
| C3 | 不等长（B 侧 +50%），正序 | 长度效应 |
| C4 | 不等长，换序 | 长度 × 位置交互 |

**三个关键控制**：

1. **等长用截短实现**，不补长——避免引入外部文本；
2. **以"回答身份"记录胜负**，不记 A/B 标签——否则会把标签偏好误记为位置偏好；
3. **同一温度、不同随机种子**生成两个回答——避免与"哪个回答更好"混淆。

### 已知设计缺陷

标签（A/B）在四个条件中始终与位置（第一位/第二位）重合，因此**目前无法分离"偏爱 A"与"偏爱第一位"**。修正方案是增加「标签交换」条件：顺序不变，但把第一段标为「回答 B」、第二段标为「回答 A」。

## 复现

```bash
pip install -r requirements.txt

# 小规模试跑（3 对）
python src/run_experiment.py --limit 3

# 全量（50 对，约 12 分钟，Apple Silicon）
python src/run_experiment.py
```

模型默认使用 `mlx-community/Qwen2.5-7B-Instruct-4bit`。可指定其他模型：

```bash
python src/run_experiment.py --model /path/to/model
JUDGE_MODEL=/path/to/model python src/run_experiment.py
```

国内网络建议从 ModelScope 下载：

```bash
pip install modelscope
modelscope download --model mlx-community/Qwen2.5-7B-Instruct-4bit --local_dir models/qwen
```

### 手动实验台

如果你只想亲手看一次"换序会不会改判"：

```bash
python src/lab.py
```

菜单支持：生成回答、粘贴自定义回答、比较两篇、交换顺序再判一次。

## 文件说明

| 路径 | 内容 |
| --- | --- |
| `src/run_experiment.py` | 主实验：生成、扰动、判定、统计 |
| `src/lab.py` | 交互式手动实验台 |
| `data/questions.json` | 50 道题（写作 15 / 知识 20 / 推理 15） |
| `results/results50.csv` | 原始结果：每对的 4 次判定、token 数、判定理由 |
| `NOTES.md` | 实验日志：假设、结果、被推翻的结论 |

`results50.csv` 字段说明：

- `len_eq_x` / `len_eq_y`：等长条件下的实际 token 数
- `len_infl`：加长一侧的 token 数
- `c1_win` ~ `c4_win`：四个条件下**胜出回答的身份**（X / Y / 平局）
- `c1_label` ~ `c4_label`：模型实际输出的 A/B 标签
- `reason_eq` / `reason_infl`：模型给出的判定理由

---

## 局限

- **单一裁判模型**：全部结论来自 Qwen2.5-7B，尚未验证是否成立于其他模型；
- **单一语言**：仅中文；
- **样本规模**：50 组配对足以看出效应量级，但不足以做细粒度子群分析；
- **标签/位置共线**：如上所述，两者的贡献尚未分离。

---

## 背景

LLM-as-a-Judge 已成为模型选型、RLHF 与榜单排序的事实标准，但裁判自身的可靠性很少被系统检验。本项目把"偏差"定义为**反事实效应**——保持内容不变，只改一个与质量无关的属性，观察判定是否翻转。这个定义可证伪，也便于跨模型复现。

相关工作：MT-Bench（Zheng et al., 2023）对位置偏差的初步观察、JudgeBench、以及多语言裁判可靠性研究。
